# timer_downloads_beta

홈덴 위성앱(체어위젯·닥터콜·대기실화면)의 **현장 검증용 베타 빌드**를 올리는 곳입니다.

## ⚠️ 자동 업데이트 피드가 아닙니다

정식 배포는 앱별 릴리즈 레포에서 하고, 현장 PC 의 자동 업데이터는 **그쪽만** 바라봅니다.

| 앱 | 정식 배포(자동 업데이트) |
|---|---|
| 체어위젯 | `timer_downloads_chair` |
| 닥터콜 | `timer_downloads_doctor_v2` |
| 대기실화면 | `timer_downloads_display_v2` |

이 레포를 **일부러 분리한 이유**가 그것입니다. 정식 피드에 베타를 섞으면
자동 업데이터의 사정권에 들어가고, 설정 한 줄(`allowPrerelease`)이 바뀌는 순간
전 체어가 베타를 받게 됩니다. 여기 올린 것은 업데이터가 주소조차 모릅니다.

**정식 배포 파일을 여기 올리지 마세요. 여기 있는 것을 정식 레포로 옮기지 마세요.**

## 올리는 형식

- **zip** 으로 올립니다 (설치기 아님). 압축을 풀어 실행하므로 기존 설치본을 건드리지 않습니다.
- 태그: `<앱>-v<버전>-beta.<n>` — 예: `chair-v2.0.88-beta.1`
- 릴리즈는 **pre-release** 로 표시합니다.

## 받는 쪽에서 지켜야 할 것

1. **기존 앱을 트레이에서 먼저 종료** — 싱글 인스턴스 잠금과 전역 단축키(부저 F13~F24)를
   기존 앱이 쥐고 있으면 베타가 조용히 꺼지거나 부저가 오지 않습니다.
2. 압축 해제 후 exe 실행.
3. 설정 파일은 정식 설치본과 **공유**합니다(appId 동일) — 테스트 중 바꾼 설정은 되돌려 놓으세요.
4. 테스트가 끝나면 베타를 종료하고 정식 앱을 다시 실행하세요.
